Appium for native desktop apps.

An Appium 3 driver for macOS, Linux and Windows. It reads the accessibility tree of the OS through xa11y and serves it over WebDriver.

appium driver install --source=npm appium-xa11y-driver

OS accessibility API

Appium and the driver run on the Host, in the logged-in Desktop session next to the app. The Client can run anywhere that can reach the port.

Quick start

1. Prepare the Host

git clone https://github.com/chinmayajha/appium-xa11y-driver
cd appium-xa11y-driver
hosts/mac/setup.sh     # or hosts/linux/setup.sh

The script installs Appium 3 and the driver, and runs Appium as a service in the Desktop session. You can run it again.

2. Start a session

{
  "platformName": "Mac",
  "appium:automationName": "Xa11y",
  "appium:app": "com.apple.TextEdit"
}

Use appium:appName to attach to a running app. With neither, the session attaches to the frontmost app.

Built on xa11y

xa11y is a Playwright-style library for native desktop apps on macOS, Windows and Linux, with Rust, Python and JavaScript APIs. The driver uses its Node bindings, so you need no Rust toolchain.
